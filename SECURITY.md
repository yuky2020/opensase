# Security policy

OpenSASE is security software, so we take reports seriously.

## Reporting a vulnerability

**Do not open a public issue.** Use GitHub's private vulnerability reporting:
<https://github.com/yuky2020/opensase/security/advisories/new>.

Please include the affected component (client, Control Plane, Edge, Connector, portal), the
version or commit, reproduction steps and the impact you see. We aim to acknowledge within
3 working days and to agree a disclosure date with you, normally within 90 days.

## Scope

All code in this repository. The project is **pre-alpha**: do not use it to protect production
traffic yet. Past internal reviews are in `docs/security/`.
